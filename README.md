# 李晨鸣 & 高雅婷的婚礼邀请

婚期：2026 年 11 月 20 日（农历十月十二，星期五）。

访问：https://lichenming0226-coder.github.io/wedding-invitation/

当前版本使用深棕色纸张和加宽的两侧蕾丝。封面为闭合蕾丝信封，带艺术 LG 火漆章；信封放大并居中，轻触后封口掀开，拍立得缓缓升起并保留一部分在信封内。提示统一为无边框文字，搭配轻微闪动的圆点。两只鸟独立飞动，织物感椭圆蕾丝相框配合平滑的照片进退场。信息标签为 DATE、TIMELINE、ADDRESS，恢复简洁线条样式，时间线居中。

## 源文件与部署

本仓库根目录的 `index.html`、`styles.css`、`app.js`、`fonts.css` 和 `assets/` 是当前维护源。GitHub Pages 从 `main` 根目录发布，`.nojekyll` 保留静态文件原样输出，无需构建。所有运行时资源均为本地相对路径。

修改在独立任务分支验证，再快进发布至 `main`。`migration-manifest.json` 记录文件校验值及可恢复的上一版本。旧的本地恢复副本不是这一版本的维护源。

- 320×568、390×844 手机布局：一屏展示，底部按钮可见，无横向溢出。

- 英文标签、完整地址与高德入口在 320×568 小屏完整显示；既有时间线与飞鸟动画保留。

## 美术素材

`assets/lace-envelope.png`、`assets/oval-lace-v2.png`、`assets/side-lace.png`、`assets/seal-lg.png` 使用内置 image_gen 根据用户提供参考图提取和重建。仅保留指定蕾丝元素，不包含参考图的人物、文字或其他装饰。提示词记录在 `art-prompts.json` 和 `art-prompts-seal.json`。
